# 🚀 Marketing AI Studio (Agency OS) - Reglas Nativas de Agente

Bienvenido al sistema **Marketing AI Studio (Agency OS)**. Este espacio de trabajo está potenciado por el marco de trabajo **Antigravity Agentic Framework v2.0**.

---

## 🎯 Configuración y Reglas Nativas
* **Cuenta y Ejecución:** Suscripción activa nativa de `diazbisac@gmail.com` (CERO API Keys necesarias).
* **Modelo Preferido:** `gemini-3.7-flash` con `--effort medium`.
* **Capacidades:** 5 Agentes Especialistas de Marketing integrados como Habilidades Nativas (Skills).

---

## ⌨️ Comandos Rápidos Directos (Slash Shortcuts)

Puedes invocar a cualquier agente o habilidad escribiendo directamente su comando:

* **`/briefing`**: Invoca al **Agente 00 (Diagnosticador)** para iniciar la entrevista y generar el Master Brief.
* **`/estratega`**: Invoca al **Agente 01 (Director Estratega)** para definir el Mecanismo Único y los 12 Ángulos.
* **`/guionugc`**: Invoca al **Agente 02 (Guionista UGC)** para escribir las tablas de producción clip a clip (0-30s).
* **`/prompts6c`**: Invoca al **Agente 03 (Ingeniero de Prompts)** para generar los prompts fotorrealistas en inglés con la fórmula 6C.
* **`/contenido`**: Invoca al **Agente 04 (Contenido Orgánico)** para crear carruseles y copys con el framework *Made to Stick* (SUCCESs).
* **`/orquestador`**: Invoca al **Orquestador Maestro** para crear la campaña completa de 5 pasos.

---

## 📋 Flujo de Trabajo Recomendado
Cuando el usuario pida ayuda para una campaña de marketing:
1. Activa **`briefing-onboarding`** para extraer la información clave y generar el Master Brief.
2. Continúa con **`director-estratega`** para definir el mecanismo único y los ángulos.
3. Invoca **`guionista-ugc`** para convertir la estrategia en guiones publicitarios.
4. Usa **`prompts-visuales-6c`** para crear las imágenes o B-rolls del anuncio.
5. Emplea **`contenido-pegajoso`** para redactar las publicaciones orgánicas complementarias.
